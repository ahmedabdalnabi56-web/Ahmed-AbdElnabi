# Publish the site

This is a static website. Upload the complete folder to Netlify or Vercel.

## Important
The contact form is configured for Netlify Forms. If you publish on Vercel, use a form service or backend endpoint for form submissions.

## Direct WhatsApp / email
No public phone number or email address is included in the supplied CV/site files, so the current version intentionally routes visitors to the contact form instead of inventing contact details. Add real phone/email before enabling direct WhatsApp/mailto buttons.
